## Как увидеть, какая работа съедает ваши деньги и лимит в Claude Code

1. Попросите Claude: «Положи скачанный файл claude-spend-by-project.py в папку ~/.claude/scripts, а если такой папки нет, создай её».
2. Попросите Claude: «Запусти python3 ~/.claude/scripts/claude-spend-by-project.py. Если внизу есть строка „Нет цены“, открой https://platform.claude.com/docs/en/about-claude/pricing, впиши цены названных там моделей в PRICES в этом файле и запусти его снова».

Проверка:

1. Вы увидите таблицу: каждая папка, где вы работали с Claude Code, сколько в ней было разговоров, сумма и её доля в общем итоге. Под ней пять самых дорогих разговоров с их первым запросом.
2. Сумма посчитана по ценам токенов Anthropic. На подписке вы её не платите; она показывает, какая работа съедает больше всего вашего лимита.
3. Чтобы увидеть только последнюю неделю, попросите Claude: «Запусти python3 ~/.claude/scripts/claude-spend-by-project.py 7».
4. Claude Code хранит журналы разговоров 30 дней, поэтому более старую работу отчёт не видит.
