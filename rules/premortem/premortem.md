# Find where the work will break, before handing it over

At the end of every finished task and in every plan, add a "What could go wrong" block.

How to put it together:
- Imagine that what was done has already failed, and name the reasons it failed.
- For each reason, find a remedy that prevents it right now.
- An item is written for the sake of the remedy, not the risk: no remedy now - no item, however big the risk.
- Something that already exists and would kick in by itself when things fail does not count as a remedy.
- The remedy is safe - apply it before you answer and write the item down as done, with the result.
- The remedy is risky or does not depend on you - name the risk and the remedy and wait for my decision.
- If a doubt can be settled by a check, check before you answer: the check found nothing - no item; it found a breakage - fix it instead of describing it.
- Only a plan or an answer to a question was asked for - change nothing and run nothing: name the remedy and wait for my decision.
- Anything that needs my consent, ask about it before the work reaches people, not after.

How to write the block:
- Not a single item - no heading and no line in its place; do not write the words "nothing found".
- Number the items so I can answer with a number.
- Do not write the block in intermediate steps inside a task.
