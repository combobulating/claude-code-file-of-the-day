# Правило для Claude Code, которое находит, где работа сломается, до того как вы её сдадите

Правило для вашего CLAUDE.md: в конце каждой задачи и плана Claude представляет, что работа провалилась, и разбирается с причинами до сдачи.

## Как поставить правило: найти, где работа сломается, до сдачи

1. Попросите Claude: «Допиши содержимое скачанного файла premortem.md в конец файла ~/.claude/CLAUDE.md, а если такого файла нет, создай его».
2. Закройте Claude Code и откройте снова: правило читается при запуске.

Проверка:

1. Попросите Claude: «Составь план, как перевести запись клиентов из бумажной тетради в Google Таблицу».
2. В конце плана Claude пишет блок «Что может пойти не так»: что он уже учёл в плане сам и что ждёт вашего решения. Без файла такого блока нет.
