# Правило для Claude Code, которое сохраняет копию перед каждой правкой и удаляет только по вашему слову

Claude Code сохраняет копию, прежде чем менять ваши таблицы и документы, говорит, как всё вернуть, и удаляет только по вашей команде, переспросив.

## Как сделать так, чтобы ошибка Claude Code не стоила вам данных

1. Попросите Claude: «Допиши содержимое скачанного файла copy-before-change.md в конец файла ~/.claude/CLAUDE.md, а если такого файла нет, создай его».
2. Закройте Claude Code и откройте снова: правила читаются при запуске.

Проверка:

1. Попросите Claude: «Создай таблицу prices.csv с тремя товарами и их ценами».
2. Закройте Claude Code и откройте снова, чтобы дальше был новый разговор.
3. Попросите Claude: «Подними все цены в prices.csv на 10 процентов». Перед правкой Claude Code сохраняет копию и говорит, как попросить старые цены обратно.
4. Попросите Claude: «Верни старые цены». Таблица становится такой, какой была до правки.
5. Попросите Claude: «Удали таблицу prices.csv». Claude Code сначала переспрашивает, что именно удалить, и удаляет только после вашего ответа.
