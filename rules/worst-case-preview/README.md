## How to see where a page breaks before your customers do

1. Ask Claude: "Add the contents of the downloaded file worst-case-preview.md to the end of the file ~/.claude/CLAUDE.md, and if that file does not exist, create it".
2. Close Claude Code and open it again: the rules are read at startup.

Check:

1. Ask Claude: "Make a product card for my website and show it to me. My products: Coffee; Green tea; 'Mountain Morning' gift set: two mugs, a coffee pot, and ground coffee in three blends".
2. Claude shows cards side by side with the longest, an ordinary, and the shortest name, and doesn't make up what you didn't give it: prices, photos, descriptions. On the long one you can see right away whether the name fits.
