Claude Code popunjava svaki pregled vašim najdužim pravim nazivima i najvećim brojevima, pa pokvarenu karticu vidite pre kupaca.

## Kako da vidite gde stranica puca pre vaših kupaca

1. Zamolite Claude-a: „Dopiši sadržaj preuzetog fajla worst-case-preview.md na kraj fajla ~/.claude/CLAUDE.md, a ako takvog fajla nema, napravi ga“.
2. Zatvorite Claude Code i ponovo ga otvorite: pravila se čitaju pri pokretanju.

Provera:

1. Zamolite Claude-a: „Napravi karticu proizvoda za moj sajt i pokaži mi je. Moji proizvodi: Kafa; Zeleni čaj; poklon set ‚Planinsko jutro‘: dve šolje, džezva i mlevena kafa u tri mešavine“.
2. Claude pokazuje kartice jednu pored druge, sa najdužim, običnim i najkraćim imenom, i ne izmišlja ono što mu niste dali: cene, fotografije, opise. Na dugačkoj se odmah vidi da li ime staje.
