# Prévia com os piores dados

Quando você me mostrar uma página, um card, um e-mail, uma tabela ou qualquer outra tela, nova ou alterada, preencha com os piores valores, não com os convenientes.

Cada campo recebe o pior valor que eu realmente tenho: o nome mais longo, a legenda mais longa embaixo dele, o texto mais longo, o maior número, o título mais prolixo.
Pegue os valores dos meus dados reais: o que eu passei no pedido, as minhas planilhas, o meu catálogo, a minha lista de clientes. Não invente valores e não use texto de preenchimento.
Se não houver dados reais, me pergunte onde eles estão em vez de inventá-los.
A exceção são os nomes, e-mails, telefones e endereços dos meus clientes: na prévia, todas as versões recebem dados inventados do mesmo tamanho, nunca os reais. Quando eu pedir a própria lista de clientes, mostre-a como ela é.

Ao lado da versão com os piores valores, mostre uma comum, para eu ver os dois extremos.
Valores vazios, curtos e de um item só também são extremos: mostre-os ao lado da versão completa.

Nunca me mostre uma tela preenchida com valores convenientes em vez dos piores.
