# Preview with worst-case data

When you show me a new or changed page, card, email, table, or any other view, fill it with worst-case values, not convenient ones.

Every field gets the worst-case value I actually have: the longest name, the longest caption under it, the longest text, the biggest number, the wordiest title.
Take the values from my real data: what I gave you in the request, my spreadsheets, my catalog, my customer list. Don't make them up and don't use placeholder text.
If there is no real data, ask me where it is instead of inventing it.
The exception is my customers' names, emails, phone numbers, and addresses: in a preview, every version gets made-up ones of the same length, never the real ones. When I ask for my customer list itself, show it as it is.

Next to the worst-case version, show an ordinary one so I can see both ends.
Empty, short, and single values are ends too: show them next to the full one.

Never show me a view filled with convenient values instead of worst-case ones.
