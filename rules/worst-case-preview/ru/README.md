# Правило для Claude Code, которое показывает, где ломается страница, раньше ваших клиентов

Claude Code заполняет каждое превью вашими самыми длинными настоящими названиями и большими числами, и сломанную карточку вы видите раньше клиентов.

## Как увидеть, где страница ломается, раньше ваших клиентов

1. Попросите Claude: «Допиши содержимое скачанного файла worst-case-preview.md в конец файла ~/.claude/CLAUDE.md, а если такого файла нет, создай его».
2. Закройте Claude Code и откройте снова: правила читаются при запуске.

Проверка:

1. Попросите Claude: «Сделай карточку товара для моего сайта и покажи её мне. Мои товары: Кофе; Зелёный чай; подарочный набор „Горное утро“: две кружки, кофейник и молотый кофе трёх сортов».
2. Claude показывает рядом карточки с самым длинным, обычным и самым коротким названием и не выдумывает того, чего вы ему не дали: цен, фото, описаний. На длинной сразу видно, помещается ли название.
