# Правило для Claude Code, которое показывает готовую работу, а не путь к файлу

Claude Code выводит короткий результат прямо в ответе, а страницы, картинки и таблицы сам открывает у вас на экране вместо пути к файлу.

## Как сразу видеть готовую работу на экране, а не искать файл

1. Попросите Claude: «Допиши содержимое скачанного файла show-the-result.md в конец файла ~/.claude/CLAUDE.md, а если такого файла нет, создай его».
2. Закройте Claude Code и откройте снова: правила читаются при запуске.

Проверка:

1. Попросите Claude: «Сделай простую одностраничную визитку для моего бизнеса, которую я смогу открыть в браузере». Если Claude Code спросит разрешение запустить команду, которая открывает файлы, разрешите. Страница сама открывается у вас на экране, а в ответе нет пути к ней.
2. Попросите Claude: «Напиши три варианта приветствия для нового клиента». Варианты приходят прямо в ответе, без отдельного файла.
