# Pravilo za Claude Code koje vam pokazuje gotov rad umesto putanje do fajla

Claude Code kratak rezultat ispisuje u odgovoru, a stranice, slike i tabele sam otvara na vašem ekranu umesto da vam da putanju do fajla.

## Kako da gotov rad odmah vidite na ekranu umesto da tražite fajl

1. Zamolite Claude-a: „Dopiši sadržaj preuzetog fajla show-the-result.md na kraj fajla ~/.claude/CLAUDE.md, a ako takvog fajla nema, napravi ga“.
2. Zatvorite Claude Code i ponovo ga otvorite: pravila se čitaju pri pokretanju.

Provera:

1. Zamolite Claude-a: „Napravi jednostavnu vizit-kartu od jedne stranice za moj posao, koju mogu da otvorim u pregledaču“. Ako Claude Code zatraži dozvolu da pokrene komandu koja otvara fajlove, dozvolite. Stranica se sama otvara na vašem ekranu, a u odgovoru nema putanje do nje.
2. Zamolite Claude-a: „Napiši tri verzije pozdrava za novog klijenta“. Verzije stižu odmah u odgovoru, bez posebnog fajla.
