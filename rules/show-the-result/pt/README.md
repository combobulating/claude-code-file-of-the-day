# Uma regra para o Claude Code que mostra o trabalho pronto em vez do caminho de um arquivo

O Claude Code escreve o resultado curto na resposta e abre páginas, imagens e planilhas na sua tela, em vez de te dar o caminho de um arquivo.

## Como ver o trabalho pronto na tela na hora, em vez de procurar um arquivo

1. Peça ao Claude: “Acrescente o conteúdo do arquivo baixado show-the-result.md ao final do arquivo ~/.claude/CLAUDE.md e, se esse arquivo não existir, crie-o”.
2. Feche o Claude Code e abra de novo: as regras são lidas na inicialização.

Verificação:

1. Peça ao Claude: “Faça um cartão de visita simples de uma página para o meu negócio, que eu possa abrir no navegador”. Se o Claude Code pedir permissão para rodar o comando que abre arquivos, permita. A página abre sozinha na sua tela, e a resposta não tem o caminho até ela.
2. Peça ao Claude: “Escreva três versões de uma saudação para um novo cliente”. As versões chegam direto na resposta, sem arquivo separado.
