Решайте за секунды: Claude Code к каждому своему вопросу предлагает лучший вариант, и для ответа хватает одной цифры.

## Как сделать, чтобы Claude к каждому вопросу давал готовое решение

1. Попросите Claude: «Допиши содержимое скачанного файла questions-with-recommendation.md в конец файла ~/.claude/CLAUDE.md, а если такого файла нет, создай его».
2. Закройте Claude Code и откройте снова: правила читаются при запуске.

Проверка:

1. Попросите Claude: «Предложи название для моей кофейни и спроси, какой вариант мне нравится». Варианты идут с номерами, рекомендуемый стоит первым, и рядом с ним Claude говорит, на чём он основан.
2. Ответьте одной цифрой, например «2». Claude сначала слово в слово повторяет второй вариант и только потом продолжает работу.
