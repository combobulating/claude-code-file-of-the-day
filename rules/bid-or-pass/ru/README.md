# Правило для Claude Code, которое за минуту говорит, браться ли за заказ

Вставьте заказ, тендер или предложение, и Claude Code ответит: подавать сейчас, не сейчас или пропустить, с одной причиной и пятью оценками.

## Как за минуту понять, браться ли за заказ

1. Попросите Claude: «Допиши содержимое скачанного файла bid-or-pass.md в конец файла ~/.claude/CLAUDE.md, а если такого файла нет, создай его».
2. Попросите Claude: «В ~/.claude/CLAUDE.md под заголовком „Чем я занимаюсь“ напиши: ..., а под заголовком „Что я не беру“: ...». Вместо точек опишите своё дело своими словами.
3. Закройте Claude Code и откройте снова: правила читаются при запуске.

Проверка:

1. Спросите Claude: «Браться ли мне за этот заказ?» и вставьте текст заказа, тендера или письма с предложением, которое вы недавно получили.
2. В первой строке Claude пишет «Подавать сейчас», «Не сейчас» или «Пропустить» с одним предложением, почему, а под ней оценку по каждому из пяти показателей, если заказ прошёл первую проверку.
