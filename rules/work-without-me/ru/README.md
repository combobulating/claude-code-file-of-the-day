# Правило для Claude Code, которое не даёт работе стоять, пока вас нет

Claude Code работает, пока вас нет: решает сам, а не ждёт ответа, и в конце пишет, что сделано, а что нет.

## Как сделать, чтобы работа шла, пока вас нет

1. Попросите Claude: «Допиши содержимое скачанного файла work-without-me.md в конец файла ~/.claude/CLAUDE.md, а если такого файла нет, создай его».
2. Закройте Claude Code и откройте снова: правила читаются при запуске.
3. Когда уходите, начните свою просьбу словами «работай без меня». Режим заканчивается с вашим следующим сообщением.

Проверка:

1. Попросите Claude: «Работай без меня. Придумай название для моей кофейни и напиши объявление об открытии». Claude не спрашивает, какое название вам нравится: он сам выбирает одно, пишет объявление и заканчивает отчётом из частей «Сделано без вас» и «Не сделано».
2. Отправьте Claude любое сообщение без этих слов: режим выключен, и в ответе нет отчёта из двух частей.
