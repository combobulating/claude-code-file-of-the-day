# Pravilo za Claude Code koje ne dozvoljava da posao stane dok vas nema

Claude Code radi dok vas nema: sam odlučuje umesto da čeka odgovor, a na kraju napiše šta je urađeno, a šta nije.

## Kako da posao ide dalje dok vas nema

1. Zamolite Claude-a: „Dopiši sadržaj preuzetog fajla work-without-me.md na kraj fajla ~/.claude/CLAUDE.md, a ako takvog fajla nema, napravi ga“.
2. Zatvorite Claude Code i ponovo ga otvorite: pravila se čitaju pri pokretanju.
3. Kada odlazite, počnite svoj zahtev rečima „radi bez mene“. Režim se završava vašom sledećom porukom.

Provera:

1. Zamolite Claude-a: „Radi bez mene. Smisli ime za moj kafić i napiši najavu otvaranja“. Claude ne pita koje vam se ime dopada: sam bira jedno, piše najavu i završava izveštajem sa delovima „Urađeno bez vas“ i „Nije urađeno“.
2. Pošaljite Claude-u bilo koju poruku bez tih reči: režim je isključen, i u odgovoru nema izveštaja iz dva dela.
