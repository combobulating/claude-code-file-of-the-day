# Правило для Claude Code, которое предлагает поставить на расписание работу, которую вы даёте снова и снова

Claude Code замечает работу, которую вы даёте ему снова и снова, одной строкой предлагает поставить её на расписание, а после вашего да ставит и запускает.

## Как Claude Code подскажет, какую работу уже можно поставить на расписание без вас

1. Попросите Claude: «Допиши содержимое скачанного файла offer-a-schedule.md в конец файла ~/.claude/CLAUDE.md, а если такого файла нет, создай его».
2. Закройте Claude Code и откройте снова: правила читаются при запуске.

Проверка:

1. Спросите Claude: «Посмотри историю наших прошлых разговоров: какую работу я даю тебе снова и снова и что из неё стоит поставить на расписание?» Claude Code назовёт эту работу и что она вам сэкономит или скажет, что ставить на расписание пока нечего.
2. Если вы согласны с предложением, ответьте «да». Claude Code сам поставит работу на расписание и сразу запустит её один раз, чтобы вы увидели результат; если он спросит разрешение запустить команду, разрешите.
3. Дальше, когда вы в третий раз даёте ему знакомую задачу и её можно делать без вас, в конце ответа появляется одна строка с предложением.
