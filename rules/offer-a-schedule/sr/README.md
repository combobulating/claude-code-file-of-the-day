# Pravilo za Claude Code koje predlaže da na raspored stavi posao koji mu dajete iznova i iznova

Claude Code primećuje posao koji mu dajete iznova i iznova, jednim redom predlaže da ga stavi na raspored, a na vaše da ga podesi i jednom pokrene.

## Kako vam Claude Code kaže koji posao već može da ide po rasporedu bez vas

1. Zamolite Claude-a: „Dopiši sadržaj preuzetog fajla offer-a-schedule.md na kraj fajla ~/.claude/CLAUDE.md, a ako takvog fajla nema, napravi ga“.
2. Zatvorite Claude Code i ponovo ga otvorite: pravila se čitaju pri pokretanju.

Provera:

1. Pitajte Claude-a: „Pogledaj istoriju naših prošlih razgovora: koji posao ti dajem iznova i iznova i šta od toga vredi staviti na raspored?“ Claude Code navodi taj posao i šta će vam uštedeti, ili kaže da za sada nema šta da se stavi na raspored.
2. Ako se slažete sa predlogom, odgovorite „da“. Claude Code sam stavlja posao na raspored i odmah ga jednom pokreće da biste videli rezultat; ako traži dozvolu da pokrene komandu, dozvolite.
3. Od tada, kada mu treći put date poznat zadatak koji može da se uradi bez vas, na kraju odgovora se pojavljuje jedan red sa predlogom.
