# Правило для Claude Code, которое ставит в конце ответа значок, чей сейчас ход

Правило для вашего CLAUDE.md: каждый ответ, который передаёт вам работу, заканчивается одним значком, и сразу видно, нужны ли вы Claude.

## Как добавить правило: значок в конце ответа Claude показывает, чей сейчас ход

1. Попросите Claude: «Допиши содержимое скачанного файла whose-turn.md в конец файла ~/.claude/CLAUDE.md, а если такого файла нет, создай его».
2. Закройте Claude Code и откройте снова: правило читается при запуске.

Проверка:

1. Попросите Claude: «Напиши короткое объявление, что моя кофейня теперь открывается в 8 утра, и сохрани его в notice.txt». Ответ заканчивается значком ✅: работа сделана, от вас ничего не нужно.
2. Попросите Claude: «Предложи два названия для моей новой кофейни, а какое взять, я решу сам». Ответ заканчивается значком ✏️: дальше нужен ваш выбор.
3. Без файла значка в конце ответа нет.
