# Правило для Claude Code, которое оставляет в проверке только замечания по делу

Попросите Claude Code проверить договор или прайс-лист, и в списке останется только то, что кому-то стоит денег, с тем, кто теряет. Пустой список - норма.

## Как оставить в списке замечаний только то, что стоит вашего времени

1. Попросите Claude: «Допиши содержимое скачанного файла real-findings.md в конец файла ~/.claude/CLAUDE.md, а если такого файла нет, создай его».
2. Закройте Claude Code и откройте снова: правила читаются при запуске.

Проверка:

1. Попросите Claude: «Найди в папке Downloads мой последний договор, прайс-лист или текст сайта, проверь его и дай список замечаний». В списке нет советов «можно было бы лучше» и замечаний о вкусе, а под каждым пунктом видно, кто теряет и что изменится после исправления.
2. Если в файле нечего исправлять, Claude так и говорит, а не придумывает пункты, чтобы заполнить список.
