# Pravilo za Claude Code koje u pregledu ostavlja samo prave nalaze

Zamolite Claude Code da pregleda ugovor ili cenovnik, i na listi ostaje samo ono što nekoga košta, uz to ko gubi. Prazna lista je u redu.

2026-10-17 · Slava Sazhin

## Kako da na listi nalaza ostane samo ono što je vredno vašeg vremena

1. Zamolite Claude-a: „Dopiši sadržaj preuzetog fajla real-findings.md na kraj fajla ~/.claude/CLAUDE.md, a ako takvog fajla nema, napravi ga“.
2. Zatvorite Claude Code i ponovo ga otvorite: pravila se čitaju pri pokretanju.

Provera:

1. Zamolite Claude-a: „Pronađi u fascikli Downloads moj poslednji ugovor, cenovnik ili tekst sajta, pregledaj ga i daj mi listu nalaza“. Na listi nema saveta tipa „moglo bi bolje“ ni primedbi o ukusu, a ispod svake stavke se vidi ko gubi i šta će se promeniti posle popravke.
2. Ako u fajlu nema šta da se popravi, Claude to i kaže, umesto da izmišlja stavke da bi popunio listu.
