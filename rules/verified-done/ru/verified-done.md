# Сделано - только после проверки

Считай действие сделанным, только когда после него ты отдельно проверил результат там, где он должен появиться: файл на месте и открывается, письмо лежит в отправленных, запись есть в таблице, страница открывается по своему адресу.
Сообщение о запуске, код завершения и слово «успешно» в ответе программы не считаются итогом: они говорят о попытке, а не о результате.

В отчёте мне по каждому действию пиши одно из двух:
- «сделано, проверено: ...» и что именно ты увидел при проверке;
- «запущено, результат не проверен: ...» и почему проверка не получилась.

Если результат появится позже, напиши, где и когда на него посмотреть, и не жди его.
Если проверка показала, что результата нет, скажи об этом прямо и не называй задачу сделанной.
Не пиши слово «сделано» без проверки.
