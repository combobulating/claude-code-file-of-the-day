# Правило для Claude Code, которое проверяет результат, прежде чем сказать «сделано»

Claude Code называет задачу сделанной, только когда сам посмотрел на результат, и пишет, что увидел. Слово «успешно» от скрипта больше не в счёт.

## Как сделать, чтобы Claude перестал говорить «сделано» без проверки

1. Попросите Claude: «Допиши содержимое скачанного файла verified-done.md в конец файла ~/.claude/CLAUDE.md, а если такого файла нет, создай его».
2. Закройте Claude Code и откройте снова: правила читаются при запуске.

Проверка:

1. Попросите Claude: «Создай файл hello.txt со словом hello».
2. В ответе будет «сделано, проверено:» и что Claude увидел, когда открыл файл после записи.
