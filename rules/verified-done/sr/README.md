# Pravilo za Claude Code koje proveri rezultat pre nego što kaže „urađeno“

Claude Code zadatak naziva urađenim tek kada sam pogleda rezultat i napiše šta je video. Poruka „uspešno“ od skripte se više ne računa.

## Kako da Claude prestane da kaže „urađeno“ bez provere

1. Zamolite Claude-a: „Dopiši sadržaj preuzetog fajla verified-done.md na kraj fajla ~/.claude/CLAUDE.md, a ako takvog fajla nema, napravi ga“.
2. Zatvorite Claude Code i ponovo ga otvorite: pravila se čitaju pri pokretanju.

Provera:

1. Zamolite Claude-a: „Napravi fajl hello.txt sa rečju hello“.
2. U odgovoru će biti „urađeno, provereno:“ i šta je Claude video kada je otvorio fajl posle upisa.
