## Kako dodati pravilo: dnevnik zadatka, da novi razgovor nastavi tamo gde ste stali

1. Zamolite Claude-a: „Dopiši sadržaj preuzetog fajla task-log.md na kraj fajla ~/.claude/CLAUDE.md, a ako takvog fajla nema, napravi ga“.
2. Zatvorite Claude Code i ponovo ga otvorite: pravilo se čita pri pokretanju.

Provera:

1. Zamolite Claude-a: „Napravi spisak za kupovinu za otvaranje kafića“. U prvom redu odgovora Claude će napisati putanju do dnevnika ovog zadatka.
2. Zatvorite Claude Code, ponovo ga otvorite i zamolite: „Hajde da nastavimo spisak za kupovinu za kafić“. Claude će naći dnevnik i nastaviti tamo gde ste stali. Bez fajla novi razgovor počinje od nule.
