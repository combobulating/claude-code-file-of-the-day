# Правило для Claude Code, которое ведёт лог задачи, чтобы новый разговор продолжил с того же места

Правило для вашего CLAUDE.md: Claude ведёт лог каждой задачи, а новый разговор читает его и продолжает с того места, где остановился прошлый.

## Как добавить правило: лог задачи, чтобы новый разговор продолжал с того места, где вы остановились

1. Попросите Claude: «Допиши содержимое скачанного файла task-log.md в конец файла ~/.claude/CLAUDE.md, а если такого файла нет, создай его».
2. Закройте Claude Code и откройте снова: правило читается при запуске.

Проверка:

1. Попросите Claude: «Составь список покупок для открытия кофейни». В первой строке ответа Claude напишет путь к логу этой задачи.
2. Закройте Claude Code, откройте снова и попросите: «Давай продолжим список покупок для кофейни». Claude найдёт лог и продолжит с того места, где вы остановились. Без файла новый разговор начинается с нуля.
