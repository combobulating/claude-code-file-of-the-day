# Лог задачи: новый разговор продолжает с того места, где мы остановились

Пришла задача или сообщение об ошибке - сразу заведи файл лога, до любой другой работы.

Файл: `~/.claude/tasks/.claude-task-[short-name].md`. Если папки нет, создай её.

Содержимое файла: задача, что уже сделано, проверенные факты с их источником, что осталось сделать.
Пиши для нового разговора, который ничего не знает о прошлом.
Результат, который есть только в ответе (список, текст, план), записывай в файл целиком: новый разговор не видит прошлых ответов.
Обновление - это переписывание: выбрасывай то, что работе больше не нужно (пересказ сделанного, повторы, черновые попытки, длинные выводы команд), а не дописывай поверх.

Порядок:
1. Пришла задача или ошибка - сначала ищи прошлые логи (пункт 2).
2. Найди все логи `.claude-task-*.md` за последние 7 дней. Есть лог этой же задачи - продолжай его, а не заводи новый. Есть логи на близкую тему - перенеси главное из них в раздел «Прошлый опыт».
3. Заведи файл лога.
4. Первая строка ответа - путь к файлу.
5. Вторая строка ответа - что нашлось в прошлых логах.
6. Обновляй файл перед каждым ответом.
7. Перед тем как разговор будет сжат, запиши в файл полное состояние.

Строки из пунктов 4 и 5 - только в ответах в чате: в файлах, коде, сообщениях коммитов и в выводе, который читает программа (JSON, CSV), их нет, даже если этот вывод и есть ответ.

Команда поиска:
```bash
find ~/.claude/tasks/ -maxdepth 1 -name ".claude-task-*.md" -mtime -7 | xargs ls -lt 2>/dev/null | head -20
```

Как выглядят первые строки ответа:
> 📋 Лог задачи: `path/to/file.md` (обновлён)
> 🔍 Прошлый опыт: [что нашлось]
