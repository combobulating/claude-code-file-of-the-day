# Uma regra para o Claude Code que anota a ideia no meio do trabalho em vez de começar a fazê-la

O Claude Code anota a ideia, o erro ou a tarefa que você menciona no meio do trabalho numa linha do plan.md e volta ao trabalho em vez de começar algo novo.

## Como parar de perder as ideias que surgem na correria

1. Peça ao Claude: “Acrescente o conteúdo do arquivo baixado note-for-later.md ao final do arquivo ~/.claude/CLAUDE.md e, se esse arquivo não existir, crie-o”.
2. Feche o Claude Code e abra de novo: as regras são lidas na inicialização.
3. No meio de qualquer trabalho, diga “anote para depois” e, em seguida, a própria ideia, erro ou tarefa.

Verificação:

1. Peça ao Claude: “Anote para depois: adicionar reservas online ao site”. O Claude vai responder em uma linha que anotou e não vai começar a fazer nada.
2. Peça ao Claude: “Mostre o arquivo plan.md”. Nele haverá uma linha com a data de hoje, a palavra “ideia” e as suas palavras.
