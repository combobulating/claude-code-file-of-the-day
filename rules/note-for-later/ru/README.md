# Правило для Claude Code, которое посреди работы записывает идею, а не бросается её делать

Claude Code записывает идею, ошибку или задачу, сказанную посреди работы, одной строкой в plan.md и возвращается к работе, а не берётся за новое.

## Как перестать терять идеи, которые приходят на ходу

1. Попросите Claude: «Допиши содержимое скачанного файла note-for-later.md в конец файла ~/.claude/CLAUDE.md, а если такого файла нет, создай его».
2. Закройте Claude Code и откройте снова: правила читаются при запуске.
3. Посреди любой работы скажите «запиши на потом» и дальше саму идею, ошибку или задачу.

Проверка:

1. Попросите Claude: «Запиши на потом: добавить на сайт онлайн-бронирование». Claude ответит одной строкой, что записал, и ничего не начнёт делать.
2. Попросите Claude: «Покажи файл plan.md». В нём будет строка с сегодняшней датой, словом «идея» и вашими словами.
