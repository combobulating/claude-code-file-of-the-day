# Pravilo za Claude Code koje usred posla zapiše ideju umesto da odmah krene da je radi

Claude Code ideju, grešku ili zadatak koji pomenete usred posla upiše kao jedan red u plan.md i vrati se poslu umesto da krene na novo.

2026-10-22 · Slava Sazhin

## Kako da prestanete da gubite ideje koje vam se jave usput

1. Zamolite Claude-a: „Dopiši sadržaj preuzetog fajla note-for-later.md na kraj fajla ~/.claude/CLAUDE.md, a ako takvog fajla nema, napravi ga“.
2. Zatvorite Claude Code i ponovo ga otvorite: pravila se čitaju pri pokretanju.
3. Usred bilo kog posla recite „zapiši za kasnije“, a zatim samu ideju, grešku ili zadatak.

Provera:

1. Zamolite Claude-a: „Zapiši za kasnije: dodati onlajn rezervacije na sajt“. Claude će u jednom redu odgovoriti da je zapisao i neće ništa početi da radi.
2. Zamolite Claude-a: „Pokaži mi fajl plan.md“. U njemu će biti red sa današnjim datumom, rečju „ideja“ i vašim rečima.
