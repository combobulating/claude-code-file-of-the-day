# Pravilo za Claude Code koje tri slova pretvara u ceo zahtev

Pravilo za vaš CLAUDE.md: dodajte zahtevu jao, nch, awm ili rbp, i Claude samo odgovara, ništa ne menja, prvo šalje plan ili traži na internetu.

## Kako dodati kratke komande: dva ili tri slova umesto celog zahteva

1. Zamolite Claude-a: „Dopiši sadržaj preuzetog fajla short-commands.md na kraj fajla ~/.claude/CLAUDE.md, a ako takvog fajla nema, napravi ga“.
2. Zatvorite Claude Code i ponovo ga otvorite: komande se čitaju pri pokretanju.
3. Svoju skraćenicu dodajete istim takvim zahtevom. Zamolite Claude-a: „Dodaj red ‚stp - kraće i konkretnije‘ u odeljak ‚Kratke komande‘ fajla ~/.claude/CLAUDE.md“.

Provera:

1. Zamolite Claude-a: „Napravi fajl menu.txt sa jelovnikom mog kafića jao“. Claude ne pravi fajl i samo odgovara rečima.
2. Zamolite Claude-a: „Napravi fajl menu.txt sa jelovnikom mog kafića awm“. Claude šalje plan i čeka vaše odobrenje.
