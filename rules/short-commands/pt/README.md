# Uma regra para o Claude Code que transforma três letras em um pedido inteiro

Uma regra para o seu CLAUDE.md: acrescente jao, nch, awm ou rbp ao pedido, e o Claude só responde, não muda nada, manda um plano antes ou pesquisa na web.

## Como adicionar comandos curtos: duas ou três letras em vez de um pedido inteiro

1. Peça ao Claude: “Acrescente o conteúdo do arquivo baixado short-commands.md ao final do arquivo ~/.claude/CLAUDE.md e, se esse arquivo não existir, crie-o”.
2. Feche o Claude Code e abra de novo: os comandos são lidos na inicialização.
3. Você adiciona a sua própria abreviação com o mesmo tipo de pedido. Peça ao Claude: “Adicione a linha ‘stp - mais curto e direto ao ponto’ à seção ‘Comandos curtos’ do arquivo ~/.claude/CLAUDE.md”.

Verificação:

1. Peça ao Claude: “Crie o arquivo menu.txt com o cardápio da minha cafeteria jao”. O Claude não cria o arquivo e só responde com palavras.
2. Peça ao Claude: “Crie o arquivo menu.txt com o cardápio da minha cafeteria awm”. O Claude manda um plano e espera a sua aprovação.
