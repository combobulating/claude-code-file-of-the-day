# Правило для Claude Code, которое превращает три буквы в целую просьбу

Правило для вашего CLAUDE.md: допишите к просьбе jao, nch, awm или rbp, и Claude только ответит, ничего не изменит, пришлёт план или поищет в интернете.

## Как добавить короткие команды: две-три буквы вместо целой просьбы

1. Попросите Claude: «Допиши содержимое скачанного файла short-commands.md в конец файла ~/.claude/CLAUDE.md, а если такого файла нет, создай его».
2. Закройте Claude Code и откройте снова: команды читаются при запуске.
3. Своё сокращение вы добавляете такой же просьбой. Попросите Claude: «Добавь строку „stp - короче и по делу“ в раздел „Короткие команды“ файла ~/.claude/CLAUDE.md».

Проверка:

1. Попросите Claude: «Создай файл menu.txt с меню моей кофейни jao». Claude не создаёт файл и только отвечает словами.
2. Попросите Claude: «Создай файл menu.txt с меню моей кофейни awm». Claude присылает план и ждёт вашего одобрения.
