## Como instalar a regra: uma marca de urgência em cada tarefa e problema nas respostas do Claude

1. Peça ao Claude: “Acrescente o conteúdo do arquivo baixado urgency.md ao final do arquivo ~/.claude/CLAUDE.md e, se esse arquivo não existir, crie-o”.
2. Feche o Claude Code e abra de novo: a regra é lida na inicialização.

Verificação:

1. Peça ao Claude: “Confira o meu plano de abrir uma cafeteria: o aluguel está pago até o fim do mês, a máquina de café chega em uma semana, ainda não tenho caixa registradora, a placa eu encomendo depois. Diga quais tarefas e problemas há aqui”.
2. Na resposta, cada tarefa e cada problema começa com uma marca colorida: ela mostra o que é urgente, o que pode esperar e o que é só uma ideia. Sem o arquivo, não há marcas.
