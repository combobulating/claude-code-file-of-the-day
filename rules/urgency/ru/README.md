# Правило для Claude Code, которое ставит значок срочности у каждой задачи и ошибки

Правило для вашего CLAUDE.md: каждая задача и ошибка в ответах Claude начинается с цветного значка, и сразу видно, что делать первым.

## Как добавить правило: значок срочности у каждой задачи и ошибки в ответах Claude

1. Попросите Claude: «Допиши содержимое скачанного файла urgency.md в конец файла ~/.claude/CLAUDE.md, а если такого файла нет, создай его».
2. Закройте Claude Code и откройте снова: правило читается при запуске.

Проверка:

1. Попросите Claude: «Проверь мой план открытия кофейни: аренда оплачена до конца месяца, кофемашину привезут через неделю, кассы пока нет, вывеску закажу потом. Напиши, какие тут задачи и ошибки».
2. В ответе каждая задача и каждая ошибка начинается с цветного значка: по нему видно, что срочно, что может подождать, а что просто идея. Без файла значков нет.
