# A Claude Code rule that marks every task and problem by urgency

A rule for your global CLAUDE.md: every task and problem Claude lists for you starts with a colored mark, so you see at once what to do first.

## How to add the rule: an urgency mark on every task and problem in Claude's answers

1. Ask Claude: "Append the contents of the downloaded file urgency.md to the end of the file ~/.claude/CLAUDE.md, and if there is no such file, create it".
2. Close Claude Code and open it again: the rule is read at startup.

Check:

1. Ask Claude: "Check my plan to open a coffee shop: the rent is paid until the end of the month, the coffee machine arrives in a week, there is no cash register yet, I will order the sign later. Tell me what tasks and problems are here".
2. In the answer, every task and every problem starts with a colored mark: it shows what is urgent, what can wait and what is just an idea. Without the file, there are no marks.
