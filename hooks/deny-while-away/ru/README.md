# Хук для Claude Code, который пропускает вопросы о разрешении, пока вас нет

Оставьте Claude Code с задачей, и он больше не ждёт час на вопросе о разрешении: шаг, которому нужно ваше «да», пропускается, остальное делается.

## Как сделать, чтобы вопрос о разрешении не останавливал работу, пока вас нет

1. Попросите Claude: «Положи скачанный файл deny-while-away.sh в папку ~/.claude/hooks/ и сделай его исполняемым».
2. Попросите Claude: «Добавь ~/.claude/hooks/deny-while-away.sh в ~/.claude/settings.json как хук PermissionRequest для всех инструментов».
3. Закройте Claude Code и откройте снова: хуки читаются при запуске.
4. Когда уходите, начните свою просьбу словами «работай без меня». Пока это ваше последнее сообщение, любой шаг, на который Claude спросил бы разрешения, пропускается, а остальная работа идёт дальше.
5. Чтобы Claude мог править файлы без вас, перед уходом нажимайте Shift+Tab, пока внизу не появится «accept edits on». В этом режиме Claude также перемещает и удаляет файлы в рабочей папке без вопросов.
6. Ваше следующее сообщение возвращает обычные вопросы о разрешении. Чтобы Claude снова спрашивал и о правке файлов, нажимайте Shift+Tab, пока внизу не появится «manual mode on».

Проверка:

1. Попросите Claude: «Работай без меня. Выполни команду curl -sI https://claude.com и покажи первую строку ответа».
2. Вопроса о разрешении нет: Claude пишет, что этот шаг пропущен, потому что спросить вас было нельзя.
3. Попросите Claude о том же без слов «работай без меня»: появляется обычный вопрос о разрешении; ответьте «No».
