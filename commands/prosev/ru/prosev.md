# Prosev - ночной просев заметок в базу знаний

ЦЕЛЬ: то, что узнано в работе и переживёт эту неделю, - устройство места, рабочая команда, найденная ловушка, предпочтение владельца, - не должно теряться в старых заметках. Скилл раз в сутки берёт заметки, изменённые за последние сутки, отбирает из них узнанное, сверяет с тем, что в базе знаний уже есть, и дописывает недостающее.

ГЛАВНОЕ: скилл ничего не удаляет и не сокращает - ни заметки, ни записи в базе знаний. Он только дописывает и правит на месте то, что в базе знаний устарело. Пустой улов - нормальный исход: в базу знаний тогда не пишется ничего.

## Шаг 1. Чтение и отбор

Прочитать каждую заметку из папки `$HOME/notes`, изменённую за последние сутки, целиком. Из каждой выписать кандидатов: одна строка на кандидата - суть и источник (имя заметки).

Мерка одна: представь новый разговор с чистого листа через три месяца, который делает другую задачу в том же месте, - сэкономит ли ему эта запись хоть один шаг.

Не берётся:
- ход и статус задачи, что сделано и что осталось;
- разовые числа замеров и даты;
- то, что читается из кода одним запросом;
- секреты в любом виде: пароль, токен, ключ. Допустима только ссылка на переменную окружения;
- личное, даже если оно попалось в рабочей заметке.

## Шаг 2. Сверка с базой знаний ДО записи

По каждому кандидату - поиск в `$HOME/knowledge/*.md` по его отличительным словам (путь, команда, имя службы, имя файла) и чтение найденного раздела целиком, не одной строки. Три исхода:
- уже написано - пропуск;
- написано иначе (устарело, расходится с заметкой) - правка на месте, с датой наблюдения в тексте правки;
- нет - дописывание в раздел подходящего по теме файла.

Новый файл в базе знаний заводится только когда ни один из существующих не подходит по теме.

## Шаг 3. Проверка записи

После записи проверить каждую правку чтением того места: текст лёг туда, куда назван, соседний текст цел. Не сошлось - вернуть файл как был.

## Формат ответа

Ошибок нет - одна строка: «Всё в порядке, всё сделано.» Она же и при пустом улове. Есть ошибки - только они, по строке на каждую.

## Правила выполнения
- ⛔ В базу знаний не пишется ни голый секрет, ни личное. Сомнение решается в пользу «не писать».
- Формулировка записи - по образцу соседних записей того же файла: тот же язык, тот же порядок.
