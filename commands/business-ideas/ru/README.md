# Повторите у себя зарубежный бизнес

Команда для Claude Code находит три зарубежных дела на одного-трёх человек, которые держатся на нейросети, с источниками цифр, и ищет похожее в вашей стране.

## Как поставить поиск дел, которые можно повторить у себя

1. Попросите Claude: «Положи скачанный файл idei-dela.md в папку ~/.claude/commands/, а если папки нет, создай её».
2. Перезапустите Claude Code.

Запуск:

1. Напишите Claude: /idei-dela Россия

Проверка:

1. Напишите Claude: /idei-dela Россия
2. Claude ищет несколько минут и выдаёт до трёх дел из других стран: чем дело занимается, где работает, сколько человек его ведёт, какую выручку или сколько пользователей оно набрало и за какой срок, есть ли похожее в России, и ссылку на источник. Без файла Claude даёт общие идеи без чисел и без источников.
