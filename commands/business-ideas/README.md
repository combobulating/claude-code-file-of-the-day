# A Claude Code command that finds a business abroad you can repeat at home

A Claude Code command finds three working businesses abroad run by one to three people on a neural network, with sources, and checks if your country has them.

Claude Code command · 2026-10-03 · by Slava Sazhin  
[Read the write-up](https://combobulating.ai/en/blog/claude-code-business-from-abroad-command) on combobulating.ai · [По-русски](ru/)

## How to install the search for businesses you can repeat at home

1. Ask Claude: "Put the downloaded file business-ideas.md into the folder ~/.claude/commands/, and if the folder does not exist, create it".
2. Restart Claude Code.

Run:

1. Write to Claude: /business-ideas Brazil

Check:

1. Write to Claude: /business-ideas Brazil
2. Claude searches for several minutes and gives up to three businesses from other countries: what the business does, where it works, how many people run it, what revenue or how many users it reached and in what time, whether something similar exists in Brazil, and a link to the source. Without the file Claude gives general ideas without numbers and without sources.
