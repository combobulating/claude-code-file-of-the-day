# Komanda za Claude Code koja svake nedelje donosi tri do pet signala o vašim konkurentima

Jednom nedeljno napišite /competitors i Claude Code donosi tri do pet signala sa datumima o tome šta su konkurenti uradili i zašto je to važno za vaš posao.

## Kako da svake nedelje saznate za važne poteze svojih konkurenata

1. Zamolite Claude-a: „Stavi preuzeti fajl competitors.md u folder ~/.claude/commands/, a ako taj folder ne postoji, napravi ga“.
2. Ponovo pokrenite Claude Code.

Pokretanje:

1. Jednom nedeljno napišite Claude-u: /competitors
2. Prvi put će vas Claude pitati čime se bavite, ko su vaši klijenti i ko su vaši konkurenti. Odgovorite jednom ili dve rečenice i navedite sajtove konkurenata.

Provera:

1. Napišite Claude-u: /competitors
2. Claude donosi tri do pet numerisanih signala. U svakom je šta je konkurent uradio, datum, link i kako to utiče na vas. Ako se ništa važno nije desilo, Claude to kaže jednom rečenicom.
3. Zamolite Claude-a: „Pokaži mi fajl ~/.claude/competitors/journal.md“. U njemu su vaš posao, vaši konkurenti i činjenice ove nedelje.
