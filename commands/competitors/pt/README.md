# Um comando para o Claude Code que traz toda semana de três a cinco sinais sobre seus concorrentes

Digite /competitors uma vez por semana e o Claude Code traz de três a cinco sinais com data sobre o que seus concorrentes fizeram e por que isso importa.

## Como saber toda semana dos movimentos importantes dos seus concorrentes

1. Peça ao Claude: “Coloque o arquivo baixado competitors.md na pasta ~/.claude/commands/ e, se a pasta não existir, crie-a”.
2. Reinicie o Claude Code.

Como usar:

1. Uma vez por semana, digite para o Claude: /competitors
2. Na primeira vez, o Claude vai perguntar o que você faz, quem são seus clientes e quem são seus concorrentes. Responda em uma ou duas frases e informe os sites dos seus concorrentes.

Verificação:

1. Digite para o Claude: /competitors
2. O Claude traz de três a cinco sinais numerados. Cada um tem o que o concorrente fez, a data, um link e como isso afeta você. Se nada importante aconteceu, o Claude diz isso em uma frase.
3. Peça ao Claude: “Mostre o arquivo ~/.claude/competitors/journal.md”. Ele tem o seu negócio, os seus concorrentes e os fatos desta semana.
