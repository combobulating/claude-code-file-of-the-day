# Команда для Claude Code, которая раз в месяц находит, что пора закрыть

Раз в месяц команда для Claude Code читает вашу выписку и называет одну вещь, которую пора закрыть, с цифрой в основании. Сама она ничего не отменяет.

## Как поставить плановое закрытие

1. Попросите Claude: «Положи скачанный файл zakrytie.md в папку ~/.claude/commands/, а если папки нет, создай её».
2. Перезапустите Claude Code.
3. Сохраните в рабочую папку выписку по счёту или карте за последние месяцы или таблицу своих расходов.

Запуск:

1. Раз в месяц напишите Claude: /zakrytie
2. Если выписки в папке нет, Claude попросит её одной строкой.

Проверка:

1. Напишите Claude: /zakrytie
2. Claude задаёт несколько вопросов о тратах из выписки и предлагает одного кандидата на закрытие: что закрыть, какой цифрой это подтверждено, что освободится, кого заденет и как всё вернуть. Сам он ничего не отменяет.
