# Komanda za Claude Code koja donosi po jednu ideju za rast vašeg posla

Napišite /idea i Claude Code donosi jednu ideju za rast vašeg posla, sa izvorom i načinom provere, i nikad ne nudi istu ideju dvaput.

## Kako da od Claude-a dobijate jednu po jednu ideju za svoj posao

1. Zamolite Claude-a: „Stavi preuzeti fajl idea.md u folder ~/.claude/commands/, a ako taj folder ne postoji, napravi ga“.
2. Ponovo pokrenite Claude Code.

Pokretanje:

1. Napišite Claude-u: /idea
2. Prvi put će vas Claude pitati čime se bavite, ko su vaši kupci i da li imate sajt. Odgovorite jednom ili dve rečenice.

Provera:

1. Napišite Claude-u: /idea
2. Claude donosi jednu numerisanu ideju: šta uraditi, na čemu se zasniva i kako ćete i posle koliko vremena videti da je uspela.
3. Odgovorite „ne“ i ponovo napišite /idea. Claude donosi drugu ideju, a ne istu drugim rečima.
4. Zamolite Claude-a: „Pokaži mi fajl ~/.claude/ideas/journal.md“. U njemu su obe ideje, a ispod prve je upisan vaš odgovor.
