# Команда для Claude Code, которая приносит по одной идее роста для вашего дела

Напишите /idea, и Claude Code принесёт одну идею роста для вашего дела, с источником и способом проверки, и не предложит одно и то же дважды.

## Как получать от Claude по одной идее для своего дела

1. Попросите Claude: «Положи скачанный файл idea.md в папку ~/.claude/commands/, а если такой папки нет, создай её».
2. Перезапустите Claude Code.

Запуск:

1. Напишите Claude: /idea
2. В первый раз Claude спросит, чем вы занимаетесь, кто ваши клиенты и есть ли у вас сайт. Ответьте одним-двумя предложениями.

Проверка:

1. Напишите Claude: /idea
2. Claude приносит одну пронумерованную идею: что сделать, на чём она основана и как и через какое время вы увидите, что она сработала.
3. Ответьте «нет» и снова напишите /idea. Claude приносит другую идею, а не ту же самую другими словами.
4. Попросите Claude: «Покажи мне файл ~/.claude/ideas/journal.md». В нём обе идеи, а под первой записан ваш ответ.
