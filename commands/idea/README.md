## How to get one idea at a time for your business from Claude

1. Ask Claude: "Put the downloaded file idea.md into the folder ~/.claude/commands/, and if the folder does not exist, create it."
2. Restart Claude Code.

Running it:

1. Type to Claude: /idea
2. The first time, Claude will ask what you do, who your customers are, and whether you have a website. Answer in a sentence or two.

Check:

1. Type to Claude: /idea
2. Claude brings one numbered idea: what to do, what it is based on, and how you will see after how long that it worked.
3. Answer "no" and type /idea again. Claude brings a different idea, not the same one in other words.
4. Ask Claude: "Show me the file ~/.claude/ideas/journal.md." It has both ideas, and your answer is written under the first one.
