# Um comando para o Claude Code que traz uma ideia de crescimento por vez para o seu negócio

Digite /idea e o Claude Code traz uma ideia de crescimento para o seu negócio, com fonte e forma de verificar, e nunca repete a mesma ideia.

## Como receber do Claude uma ideia de cada vez para o seu negócio

1. Peça ao Claude: “Coloque o arquivo baixado idea.md na pasta ~/.claude/commands/ e, se a pasta não existir, crie-a”.
2. Reinicie o Claude Code.

Como usar:

1. Digite para o Claude: /idea
2. Na primeira vez, o Claude vai perguntar o que você faz, quem são seus clientes e se você tem um site. Responda em uma ou duas frases.

Verificação:

1. Digite para o Claude: /idea
2. O Claude traz uma ideia numerada: o que fazer, em que ela se baseia e como e depois de quanto tempo você vai ver que funcionou.
3. Responda “não” e digite /idea de novo. O Claude traz uma ideia diferente, não a mesma com outras palavras.
4. Peça ao Claude: “Mostre o arquivo ~/.claude/ideas/journal.md”. Ele tem as duas ideias, e a sua resposta está escrita embaixo da primeira.
