# Субагент для Claude Code, который ищет по коду и не съедает ваш контекст

## Как поставить агента-разведчика по коду

Агент ищет по коду в своём контексте и возвращает главной сессии только адреса: путь и номер строки. Главная сессия не тратит свой контекст на чтение файлов, а сам поиск идёт на той модели, которую вы зададите агенту.

Куда положить:
```
mkdir -p ~/.claude/agents
cp agent-kod-razvedka.md ~/.claude/agents/
```

Что вписать своё: в строке `model` - модель, на которой пойдёт поиск: `haiku`, `sonnet`, `opus`, `fable`, полный идентификатор модели или `inherit` (модель главной сессии). В строке `effort` - уровень усилий: `low`, `medium`, `high`, `xhigh` или `max`; какие уровни доступны, зависит от модели.

Как убедиться, что заработало: откройте новую сессию Claude Code и попросите:
```
Через агента kod-razvedka найди, где в этом проекте определена функция <имя>
```

Пока агент работает, команда `/tasks` показывает его строку и модель, на которой он идёт. В ответ придут строки вида `путь:номер_строки - что там`, а не содержимое файлов.
