# Субагент для Claude Code, который делает непонятный ответ простым

Напишите, что ничего не поняли, и субагент для Claude Code перепишет последний ответ короче и проще, с теми же цифрами, выводами и вопросами к вам.

## Как поставить упростителя ответов

1. Попросите Claude: «Положи скачанный файл uprostitel.md в папку ~/.claude/agents/, а если папки нет, создай её».
2. Попросите Claude: «Запиши в ~/.claude/CLAUDE.md правило: когда я пишу, что твой ответ непонятный или слишком длинный, зови uprostitel, передай ему дословно свой последний ответ и мои слова, а его текст покажи мне как есть».
3. Перезапустите Claude Code.

Проверка:

1. Попросите Claude: «Объясни, чем резервная копия отличается от синхронизации файлов».
2. Напишите: «Ничего не понял, слишком длинно».
3. Claude зовёт uprostitel и показывает тот же ответ короче и проще, без новых фактов.
