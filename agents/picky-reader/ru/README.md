# Субагент для Claude Code, который читает ваш текст глазами адресата

Субагент для Claude Code читает письмо, пост или предложение глазами адресата до отправки и делит замечания на блокирующие и необязательные.

## Как поставить придирчивого читателя

1. Попросите Claude: «Положи скачанный файл pridirchivyy-chitatel.md в папку ~/.claude/agents/, а если папки нет, создай её».
2. Попросите Claude: «В конце файла ~/.claude/agents/pridirchivyy-chitatel.md допиши строку: кто мои клиенты и что для них важнее всего».
3. Попросите Claude: «Запиши в ~/.claude/CLAUDE.md правило: перед отправкой любого моего текста людям зови pridirchivyy-chitatel и показывай мне его отчёт».
4. Перезапустите Claude Code.

Проверка:

1. Попросите Claude: «Позови pridirchivyy-chitatel: проверь письмо клиенту "Здравствуйте! Счёт во вложении, оплатить нужно сегодня до 18:00." Вложения у письма нет».
2. Первой строкой отчёта идёт роль, например клиент, который получил письмо.
3. В блокирующем стоит, что письмо обещает счёт, которого нет.
