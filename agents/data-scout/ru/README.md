# Субагент для Claude Code, который собирает данные, а выводы оставляет вам

Субагент для Claude Code выполняет запросы, дописывает результаты с источниками в общий файл и отвечает в одну-две строки. Выводы остаются за вами.

## Как поставить сборщика данных

1. Положите `data-scout.md` в папку `~/.claude/agents/`.
2. В строках `model` и `effort` поставьте модель и уровень усилий, которые выделяете на сбор данных.
3. В строке `tools` оставьте только инструменты, которые нужны для сбора.
4. Перезапустите Claude Code.

Проверка:

1. Наберите `@` и найдите `data-scout` в подсказке.
2. Попросите: «Позови data-scout: пусть сложит в файл /tmp/proba.md число файлов в текущей папке и вернёт статус».
3. Ответ сборщика - одна-две строки, а число и команда, которой оно получено, лежат в `/tmp/proba.md`.
